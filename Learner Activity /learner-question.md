## Learner Activity: Designing an AI-Powered Movie Recommendation System

### Scenario

Imagine you are designing a movie recommendation system for a streaming platform. The system needs to store information about movies, find movies that match a user's preferences, and use AI to predict which movies the user might enjoy.

### Task 1: Choose a Data Structure

The platform has thousands of movies. Each movie has a title, genre, release year, and user rating.

1. Which data structure would you use to store the movie information: an array/list, a hash table, or a graph?
2. Explain why your chosen data structure is suitable for this task.
3. If the platform needs to find a movie quickly by its unique ID, how could a hash table help?

### Task 2: Design an Algorithm

A user enjoys science fiction movies with ratings of 4 stars or higher.

1. Write a simple algorithm in pseudocode to find all movies that match these preferences.
2. Identify the input, the processing steps, and the output.
3. Explain how the algorithm's efficiency might change as the number of movies increases.

### Task 3: Apply Connectionist AI

The platform wants to go beyond fixed rules and predict a user's preferences using a neural network.

1. Explain how a neural network could learn from the user's previous ratings and viewing history.
2. Identify the input features and the prediction the model should produce.
3. Explain one advantage of using a neural network instead of a fixed algorithm, and one potential limitation.

### Reflection Question

How do algorithms, data structures, and connectionist AI work together to create an effective recommendation system? What problems might occur if one of these components is poorly designed?

### Challenge

Suggest one improvement that could make the recommendation system faster, more accurate, or fairer. Justify your choice using concepts from the lesson.
