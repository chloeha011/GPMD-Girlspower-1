## 2. Project Overview

### Purpose

This project aims to help beginners understand three fundamental areas of computer science: algorithms, data structures, and connectionist artificial intelligence (AI).

Through clear explanations, practical examples, visual materials, and learning activities, we aim to make technical concepts easier to understand and apply.

The project also explores how these three areas work together in real-world applications.

### Intended Learners

Our learning materials are designed for beginners who have little or no previous experience with computer science or artificial intelligence.

No advanced programming knowledge is required. Basic computer literacy, logical thinking, and simple mathematical skills are sufficient to begin learning.

### Learning Objectives

By the end of the learning module, learners should be able to:

- Explain what algorithms are and how they solve problems.
- Understand basic searching and sorting algorithms.
- Identify common data structures and describe their purposes.
- Explain the basic structure and learning process of artificial neural networks.
- Recognize real-world applications of connectionist AI.
- Describe how algorithms, data structures, and AI work together in computer applications.

## 3. Module Structure

The project focuses on three major topics: **Algorithms, Data Structures, and Connectionist Artificial Intelligence**. The module is designed to help beginners understand these concepts through structured explanations, practical examples, visual materials, and learning activities.

The `general-documents/` folder in the `GENERAL` branch contains five documents that define the module's learning objectives, content structure, prerequisites, planned activities, and development progress.

### 3.1 Module Planning Documents

- [Introduction and Learning Objectives](./general-documents/01_Introduction_and_Learning_Objectives.md) — introduces the module, its purpose, and expected learning outcomes.
- [Major Topics and Subtopics](./general-documents/02_Major_Topics_and_Subtopics.md) — outlines the main topics, subtopics, and their logical learning sequence.
- [Prerequisite Knowledge](./general-documents/03_Prerequisite_Knowledge.md) — identifies the foundational knowledge learners need before starting the module.
- [Planned Examples and Learner Activities](./general-documents/04_Planned_Examples_and_Learner_Activities.md) — describes planned examples, demonstrations, practice tasks, and application questions.
- [Development Status and Task Plan](./general-documents/05_Development_Status_and_Task_Plan.md) — tracks the progress of each section, completed work, and remaining tasks.

Together, these documents provide an overview of the module's design and guide the development of the learning materials.

### 3.2 Main Learning Topics

The learning module covers the following topics:

1. **Algorithms:** Understanding algorithms, their representations, searching and sorting methods, and basic algorithm efficiency.
2. **Data Structures:** Exploring how data is organized, stored, and accessed.
3. **Connectionist Artificial Intelligence:** Understanding neural networks and how they learn patterns from data.
4. **Connections Between the Topics:** Examining how algorithms and data structures support AI applications.

Each topic will be supported by explanations, worked examples, visual materials, and learner activities as the module develops.
