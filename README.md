## 3. Project Purpose, Learners and Goals

### Purpose
This project helps beginners understand three fundamental areas of computer science: **algorithms**, **data structures**, and **connectionist AI** (neural networks). It uses clear explanations, worked examples, visuals, and learner activities with checked answers, and it shows how the three areas work together in real applications.

### Intended learners
Beginners with little or no experience in computer science or AI. No advanced programming is needed. Basic computer literacy, logical thinking, and simple mathematics are enough. See [Prerequisite Knowledge](./general-documents/03_Prerequisite_Knowledge.md).

### Learning goals
By the end of the module, learners should be able to:

1. Explain what an algorithm is and how it solves a problem.
2. Describe and trace basic searching and sorting algorithms.
3. Identify common data structures and explain what each is used for.
4. Explain the basic structure and learning process of an artificial neural network.
5. Recognize real-world applications of connectionist AI.
6. Describe how algorithms, data structures, and AI work together in computer applications.

## 8. Topics Covered

1. **Algorithms:** what algorithms are and their characteristics, linear and binary search, bubble and selection sort, Big O notation, time and space complexity.
2. **Data Structures:** arrays, linked lists, stacks, queues, trees and graphs, with traversal and a comparison of when to use each.
3. **Connectionist AI:** neurons, weights, bias, activation functions, layers, forward propagation, loss functions, backpropagation, gradient descent, applications and limitations.
4. **Connections:** how algorithms and data structures support AI, including a data structure selection challenge and a comparison of neural networks with rule-based systems.

## 11. Known Limitations

- Slides and videos are submitted separately and are not stored here.
- Neural network learning is explained at an introductory, conceptual level. Full mathematical derivations (for example of backpropagation) are not covered.
- Only two searching algorithms (linear, binary) and two sorting algorithms (bubble, selection) are covered. Faster sorting methods such as merge sort and quicksort are not included.
- Hash tables are defined in the data structures terminology but are not taught as a full topic.
- The content lives on separate branches, so links between branches use GitHub URLs and need an internet connection when viewed online.
