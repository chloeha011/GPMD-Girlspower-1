# VISUALS — Algorithms, Data Structures, and Connectionist AI

## 1. Purpose

This branch contains visual materials for our project. The goal is to make technical concepts easier to understand through clear diagrams, illustrations, and step-by-step examples.

The visuals will support our learning module and can later be used in the Study Guide, PPT Slides, and Video Tutorials.

## 2. Folder Structure

The `VISUALS` branch contains visual materials for three main topics: Algorithms, Connectionist AI, and Data Structures.

## 3. Development Status

Visual materials will be developed alongside the content in the corresponding sections.

- **Planned:** Visual ideas have been identified.
- **Drafted:** The visual is being created or has an initial version.
- **Needs revision:** The visual needs improvement or correction.
- **Checked:** The visual has been reviewed for accuracy, readability, and consistency with the learning module.

The status of each visual will be updated as the project progresses.

## 4. Design Principles

All visuals should:

- Be clear and easy for beginners to understand.
- Use consistent labels, fonts, and design styles.
- Support the learning content rather than serve only as decoration.
- Match the explanations and examples in the CONTENT branch.
- Include source attribution when external materials are used.
