## 1. STACK: LAST IN, FIRST OUT (LIFO)

A stack stores items so that the last item added is the first item removed. Imagine a pile of plates: you normally take the top plate first.

### Worked Example
```python
stack = []
print("Start with an empty stack:", stack)

stack.append(10)
print("After append(10):", stack)

stack.append(20)
print("After append(20):", stack)

stack.append(30)
print("After append(30):", stack)
print("The top item is stack[-1]:", stack[-1])

removed_item = stack.pop()
print("pop() removes:", removed_item)
print("Stack after pop():", stack)

class Node:
    """One node in a singly linked list."""
    def __init__(self, data):
        self.data = data
        self.next = None

def display_linked_list(head):
    """Print every value by following the links from the head node."""
    current = head
    values = []
    while current is not None:
        values.append(str(current.data))
        current = current.next
    print(" -> ".join(values) + " -> None")

# Create nodes
first = Node(10)
second = Node(20)
third = Node(30)

# Link them together
first.next = second
second.next = third

print("Original list:")
display_linked_list(first)

# Insert a new node with value 5 at the beginning
new_node = Node(5)
new_node.next = first
first = new_node
print("\nAfter inserting 5 at the beginning:")
display_linked_list(first)

## 4. COMPARING THE DATA STRUCTURES

*   **Stack:**
    *   Rule: LIFO (last in, first out)
    *   Add: `append()`
    *   Remove: `pop()`
    *   Example use: Undo operations
*   **Queue:**
    *   Rule: FIFO (first in, first out)
    *   Add: `append()`
    *   Remove: `popleft()`
    *   Example use: Waiting lines
*   **Linked List:**
    *   Structure: Nodes connected by references
    *   Access: Follow links from the head
    *   Example use: Learning how linked collections work

There is no single best data structure for every situation. The right choice depends on how the program needs to store, access, add, or remove data.
