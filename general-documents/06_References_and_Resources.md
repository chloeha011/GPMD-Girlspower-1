# References and Resources

This document collects the resources used to understand the main topics and prepare our learning materials. We will update the list when new sources are used.

## 1. Algorithms and Data Structures

1. Python Software Foundation. *Data Structures — Python Tutorial.*  
   https://docs.python.org/3/tutorial/datastructures.html  
   Used for: Understanding lists, stacks, queues, and basic data organization.

2. OpenDSA. *Data and Algorithm Analysis.*  
   https://opendsa.org/OpenDSA/Books/Catalog/html/AAIntro.html  
   Used for: Background reading on algorithms and algorithm analysis.

3. OpenDSA. *Introduction to Hashing.*  
   https://opendsa.cs.vt.edu/ODSA/Books/cnu/cpsc270/spring-2021/TR1100_TR1330/html/HashIntro.html  
   Used for: Understanding hash tables and how they support searching and data retrieval.

## 2. Connectionist AI and Neural Networks

4. IBM. *What Is a Neural Network?*  
   https://www.ibm.com/think/topics/neural-networks  
   Used for: Understanding the basic structure of neural networks and how they recognize patterns.

5. Google for Developers. *Recommendations: What and Why?*  
   https://developers.google.com/machine-learning/recommendation/overview?hl=en  
   Used for: Understanding recommendation systems and how machine learning can help predict user preferences.
