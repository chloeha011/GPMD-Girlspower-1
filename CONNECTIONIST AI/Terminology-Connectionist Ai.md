Terminology: Connectionist AI

This section introduces the key terms related to connectionist artificial intelligence (AI) and explains them in simple language to help beginners understand how neural networks work and learn from data.

1. Connectionist AI

Connectionist AI is an approach to artificial intelligence inspired by the way biological neurons connect and communicate. It uses artificial neural networks to learn patterns from data and make predictions or decisions.

Example: An AI system that learns to recognize cats in pictures.

2. Artificial Neural Network

An artificial neural network (ANN) is a computational model made up of interconnected artificial neurons organized into layers. It learns patterns from examples during training.

Example: A neural network trained to identify handwritten numbers.

3. Artificial Neuron

An artificial neuron is a basic computational unit in a neural network. It receives inputs, processes them using weights and a bias, and produces an output.

Example: A neuron may help a network identify whether a small part of an image contains a particular visual feature.

4. Input Layer

The input layer is the first layer of a neural network. It receives the information that the network will process.

Example: In an image-recognition system, the input may consist of numerical values representing image pixels.

5. Hidden Layer

A hidden layer is a layer between the input and output layers. It processes information and helps the network learn useful patterns in the data.

Example: In an image-recognition network, hidden layers may learn to detect edges, shapes, and more complex visual features.

6. Output Layer

The output layer produces the final result of a neural network, such as a prediction or classification.

Example: A network analyzing an image may output probabilities indicating whether the image contains a cat, a dog, or another animal.

7. Weights

Weights are numerical values that determine how strongly different inputs influence a neuron. During training, a neural network adjusts its weights to improve its predictions.

Example: A network may learn that certain image features are more useful than others for recognizing cats.

8. Bias

Bias is a learnable numerical value that helps a neuron adjust its output independently of its weighted inputs.

Example: Adjusting a neuron’s bias can change how easily it activates in response to its inputs.

9. Activation Function

An activation function determines a neuron’s output based on its calculated input. It helps neural networks learn complex patterns.

Example: The ReLU activation function outputs zero for negative inputs and returns the input itself for positive inputs.

10. Training Data

Training data is the information used to teach a neural network to recognize patterns and make predictions. It may include images, text, audio, or numerical information.

Example: A collection of labeled cat and dog pictures can be used to train an image-classification model.

11. Neural Network Training

Neural network training is the process of adjusting a network’s learnable parameters using data to improve its performance on a task.

Example: A network repeatedly processes labeled animal pictures and updates its weights to reduce prediction errors.

12. Prediction

A prediction is the result produced by a trained neural network when it processes new input data.

Example: After analyzing a picture, a network predicts that it contains a cat.

13. Loss Function

A loss function measures how different a neural network’s prediction is from the expected answer. During training, the model aims to reduce this loss.

Example: If a network predicts the wrong animal, its loss function measures the prediction error according to the task.

14. Backpropagation

Backpropagation is a method used to calculate how the network’s parameters contributed to its prediction error. These calculations help the training process determine how to adjust the weights.

Example: After making an incorrect prediction about an image, a network uses backpropagation to calculate information needed to improve its next predictions.

15. Generalization

Generalization is a neural network’s ability to apply patterns learned from training data to new, previously unseen examples.

Example: A model trained on many cat pictures can recognize a cat in a new picture it has never seen before.
