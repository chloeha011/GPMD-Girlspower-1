 Check Understanding

The learner should be able to explain the concepts in their own words and apply them to a new example.

Knowledge Check

1. What is an algorithm?

* [x]	A sequence of instructions for solving a problem
* [ ]	A structure that stores data
* [ ]	A neural network that learns patterns

2. Which data structure follows LIFO?

* [ ]	Queue
* [x]	Stack
* [ ]	Array

3. How does a connectionist AI model typically improve during training?

* [ ]	By randomly storing more data only
* [ ]	By following a fixed list of every possible answer
* [x]	By adjusting network weights based on prediction errors

4. How are algorithms and data structures related?

* [x]	Algorithms use data structures to organize and process information
* [ ]	They are two names for the same concept
* [ ]	Data structures always learn independently from examples

Expected Learning Outcome

The learner can define algorithms, distinguish common data structures, explain how connectionist AI learns from data, and describe how algorithms and data structures support the development and operation of AI systems.
