Terminology: Algorithms

This section introduces the key terms related to algorithms and explains them in simple language to help beginners understand how algorithms work.

1. Algorithm

An algorithm is a sequence of clear, ordered instructions used to solve a problem or complete a task. For example, a recipe follows an algorithm because it provides steps to prepare a meal.

2. Searching Algorithm

A searching algorithm is a method used to find a specific item in a collection of data. For example, searching for a student’s name in a list is an everyday example.

3. Sorting Algorithm

A sorting algorithm arranges data in a particular order, such as from smallest to largest or alphabetically. Sorting helps make information easier to organize and find.

4. Linear Search

Linear search checks each item in a collection one by one until the target item is found or there are no more items to check. It can be used with both sorted and unsorted data.

Example: To find the number 8 in [2, 5, 8, 12, 16], linear search checks 2, then 5, and finally 8.

5. Binary Search

Binary search finds an item by repeatedly dividing a sorted collection into smaller halves. It checks the middle item and continues searching in the appropriate half.

Example: To find 12 in [2, 5, 8, 12, 16], binary search checks the middle value, 8, and then searches the right half.

6. Bubble Sort

Bubble sort repeatedly compares neighboring elements and swaps them when they are in the wrong order. This process continues until the collection is sorted.

Example: [5, 2, 4] becomes [2, 4, 5] after the elements are compared and swapped as needed.

7. Selection Sort

Selection sort repeatedly finds the smallest element in the unsorted part of a collection and moves it to the correct position.

Example: When sorting [5, 2, 4], selection sort first finds 2 and places it at the beginning.

8. Input

Input is the information or data given to an algorithm to process.

Example: In an algorithm that adds two numbers, the numbers 5 and 3 are the inputs.

9. Output

Output is the result produced after an algorithm processes its input.

Example: If an algorithm adds 5 and 3, the output is 8.

10. Time Complexity

Time complexity describes how the amount of work an algorithm performs grows as the input size increases. It helps us compare the efficiency of different algorithms.

Example: Linear search may need to check every item, while binary search can eliminate half of the remaining search area at each step when the data is sorted.

11. Pseudocode

Pseudocode describes an algorithm using simple, structured language without requiring the exact rules of a programming language. It helps people plan their solutions before writing code.

Example:

1. Start.
2. Read two numbers.
3. Add the numbers.
4. Display the result.
5. Stop.

12. Condition

A condition is a rule that determines what an algorithm should do in a particular situation. It is often expressed using statements such as if and else.

Example: If a number is greater than 10, display “Large”; otherwise, display “Small or equal to 10.”

13. Loop

A loop repeats a set of instructions until a specified condition is met or a defined number of repetitions is completed.

Example: An algorithm can use a loop to check every number in a list.

14. Efficiency

Efficiency describes how effectively an algorithm uses resources, such as time and memory, to complete a task. An efficient algorithm solves a problem while avoiding unnecessary work.

15. Big O Notation

Big O notation describes how an algorithm’s resource requirements grow as the input size increases. Common examples include O(1), O(n), and O(log n).

Example: Linear search has a worst-case time complexity of O(n), while binary search has a worst-case time complexity of O(log n) on sorted data.
